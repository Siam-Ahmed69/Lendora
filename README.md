# Lendora 🇧🇩

**Own Less. Experience More.**  
Lendora is a trusted peer-to-peer sharing and rental marketplace specifically designed for the creative and professional community in Bangladesh.

## 🚀 Overview

Lendora empowers creators in Dhaka to rent high-end cinema gear, book professional daylight studios, and hire technical expertise without the burden of ownership. Built with a focus on trust, security, and the local ecosystem.

### Key Categories:
- 🎥 **Cinema & Optics:** Sony Alpha kits, RED packages, and lenses.
- 🏢 **Creative Spaces:** Daylight lofts in Dhanmondi, studios in Banani.
- 🛠️ **Expertise & Tech:** Technical mentors, high-end editing rigs, and more.

## ✨ Features

- **Hyper-Local Search:** Optimized for Dhaka neighborhoods (Gulshan, Banani, Dhanmondi, Uttara).
- **Secure Escrow (Vision):** Designed for bKash, Nagad, and local card payments.
- **NID Verification:** Trust-first approach with mandatory Bangladesh National ID checks.
- **Interactive UI:** Smooth transitions and responsive design using Framer Motion.
- **Zero-Latency Browsing:** Client-side mock data management for instant prototyping.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Data Handling:** LocalStorage (for prototype persistence)

## 🏁 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/lendora.git
   cd lendora
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open the app:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the result.

## 📂 Project Structure

- `/app`: Next.js App Router pages and API routes.
- `/components`: Reusable UI components (Navbar, Footer, ListingCard, etc.).
- `/lib`: Utility functions, types, and mock data.
- `/public`: Static assets and images.
